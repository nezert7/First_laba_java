# Практическая работа №1: Матрицы комплексных чисел

Консольное Java-приложение для выполнения базовых операций над матрицами с комплексными элементами.

## Структура проекта

Пакет `matrixapp`:
* `ComplexNumber.java` — класс комплексного числа вида a + bi: сложение, вычитание, умножение, деление и парсинг строкового ввода.
* `ComplexMatrix.java` — класс матрицы комплексных чисел: сложение, умножение, деление (A * B^-1), транспонирование, определитель и нахождение обратной матрицы (метод Гаусса).
* `Main.java` — консольный интерфейс (меню, ввод матриц, вывод результатов и перехват ошибок).

## Реализованный функционал

1. **Сложение матриц (A + B)** — проверка совпадения размерностей.
2. **Перемножение матриц (A * B)** — проверка равенства числа столбцов матрицы A числу строк матрицы B.
3. **Деление матриц (A / B)** — умножение первой матрицы на обратную ко второй через метод Гаусса-Жордана. Выброс ошибки при вырожденной матрице B (det = 0).
4. **Транспонирование (A^T)** — смена строк и столбцов местами.
5. **Вычисление определителя (det(A))** — прямой ход метода Гаусса с выбором главного элемента (только для квадратных матриц).

## Формат ввода чисел

Элементы матриц вводятся построчно через пробел в стандартном виде:
* Вещественные: `5`, `-3.2`
* Мнимые: `i`, `-i`, `2i`, `-4.5i`
* Полная форма: `1+2i`, `3-4i`, `-2.5+1.5i`
